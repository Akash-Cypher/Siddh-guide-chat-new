Siddh Guide Chat Widget – WordPress Integration Guide

Hi Team,

Please follow the steps below to integrate the Siddh Guide Chat Widget into the website.

This chatbot connects WordPress to our AWS backend securely through a proxy plugin.

1️⃣ Install the Proxy Plugin

This plugin connects WordPress to the chatbot backend securely.

Create this folder
wp-content/plugins/siddh-guide-chat-proxy/
Upload this file inside that folder
siddh-guide-chat-proxy.php
Then activate it

Go to:

WordPress Admin → Plugins

Activate:

Siddh Guide Chat Proxy
2️⃣ Add API Key (Important)

Open the WordPress configuration file:

wp-config.php

Add this line near the bottom:

define('SIDDH_CHAT_API_KEY', '<<API KEY WILL BE SHARED PRIVATELY>>');

⚠️ Important

Do NOT place the API key inside JavaScript.

The key must remain server-side only.

3️⃣ Upload Widget Files to Theme

Inside the active theme, create this folder:

wp-content/themes/<active-theme>/assets/siddh-chat/

Upload these files into that folder:

siddh-guide-chat-widget.js
style.css
siddhanta-logo.png

Do NOT upload them as a separate page or open the HTML file directly.

4️⃣ Load the Widget Files

Open the theme file:

functions.php

Add this code:

function siddh_guide_chat_assets() {

  wp_enqueue_style(
    'siddh-guide-chat-css',
    get_stylesheet_directory_uri() . '/assets/siddh-chat/style.css',
    [],
    '1.0'
  );

  wp_enqueue_script(
    'siddh-guide-chat-js',
    get_stylesheet_directory_uri() . '/assets/siddh-chat/siddh-guide-chat-widget.js',
    [],
    '1.0',
    true
  );

}

add_action('wp_enqueue_scripts', 'siddh_guide_chat_assets');

This loads the chatbot CSS and JavaScript on the website.

5️⃣ Add the Chat Widget HTML

Open the Landing Page in the WordPress editor.

Add a Custom HTML block.

Paste the contents of:

siddh-guide-chat-widget.html

inside that block.

⚠️ Important

Update the logo path if required.

Example:

<img src="/wp-content/themes/<active-theme>/assets/siddh-chat/siddhanta-logo.png">
6️⃣ Clear Cache

If the site uses caching (WP Rocket / Cloudflare / etc):

Please clear the cache after uploading the files.

7️⃣ Test the Chatbot

Visit the landing page.

You should see the chat bubble in the bottom-right corner.

Test with:

hello

Expected result:

The chatbot should reply with a welcome message.

Expected Request Flow

The browser will send requests to:

/wp-json/siddh/v1/chat

The proxy plugin forwards it to the AWS backend.

If Something Looks Wrong

Please verify:

Plugin is activated

JS file is loaded

CSS file is loaded

API key exists in wp-config.php
