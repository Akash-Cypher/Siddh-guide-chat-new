Ask Sid — WordPress Integration Guide
=====================================

Hi Team,

Ask Sid is the chat assistant for the Siddhanta website. It ships as a single
WordPress plugin. The plugin renders the chat widget AND acts as a secure proxy
to our AWS backend, so the API key never reaches the browser.

You will receive two things:

  1. siddh-guide-chat.zip   <- the plugin
  2. the API key            <- sent separately, never in the same message

Total setup time: about 10 minutes.


--------------------------------------------------------------------------
1. INSTALL THE PLUGIN
--------------------------------------------------------------------------

WordPress Admin -> Plugins -> Add New -> Upload Plugin

  - Choose siddh-guide-chat.zip
  - Install Now
  - Activate

The plugin appears in the list as "Ask Sid".

Do NOT unzip it manually into wp-content/plugins/. Upload the .zip as-is.
Do NOT copy any files into the theme. Earlier versions of this guide asked for
that; it is no longer needed and will cause the scripts to load twice.


--------------------------------------------------------------------------
2. ADD THE API KEY
--------------------------------------------------------------------------

Open wp-config.php and add this line ABOVE the line that says
/* That's all, stop editing! */

  define('SIDDH_CHAT_API_KEY', 'PASTE-THE-KEY-HERE');

Important:
  - The key must stay server-side. Never put it in JavaScript, a page, or a
    theme file.
  - Do not commit wp-config.php to any public repository.

Alternative (less secure, use only if you cannot edit wp-config.php):
  WordPress Admin -> Ask Sid KB -> Settings -> paste the key -> Save.


--------------------------------------------------------------------------
3. PUT THE WIDGET ON THE SITE
--------------------------------------------------------------------------

Edit the page where the chat bubble should appear (normally the landing page).

Add a Shortcode block containing exactly:

  [siddh_guide_chat]

Save/Update the page.

That is the whole integration. The plugin loads its own CSS and JavaScript --
there is nothing to add to functions.php and no HTML to paste anywhere.

To show the bubble on every page instead, add the shortcode to the footer
template or a footer widget area.


--------------------------------------------------------------------------
4. CLEAR CACHES
--------------------------------------------------------------------------

If the site uses WP Rocket, LiteSpeed, W3 Total Cache, Cloudflare, or similar:

  Purge the FULL page cache after installing.

Why this matters: the plugin versions its own asset URLs automatically, so an
updated script gets a fresh URL. But the cached PAGE still points at the old
URL until the page cache is purged. Purge once after install and after every
plugin update.


--------------------------------------------------------------------------
5. TEST IT
--------------------------------------------------------------------------

Open the page in a normal browser window and check each of these:

  [ ] The orange chat bubble appears at the bottom-right.
  [ ] Type "hello" -> you get a greeting back.
  [ ] Ask "how many courses are there" -> you get a number.
  [ ] Ask "who are you" -> it answers "I'm Ask Sid ...".

Then check the conversation memory:

  [ ] Say "I am an engineer."
  [ ] Then "Suggest me a course."      -> should use your engineering background
  [ ] Then "Why did you select that course?"  -> should explain the choice
  [ ] Then "What is its duration?"     -> should answer for the same course

Then check that a refresh starts fresh (this is intended behaviour):

  [ ] Press F5 to reload the page.
  [ ] Ask "What is my stream?"
      -> Expected: "I don't know your stream yet. Please tell me your field or
         background."
      -> It must NOT say engineering. Each page load is a new conversation.


--------------------------------------------------------------------------
HOW THE CONVERSATION WORKS (please do not "fix" this)
--------------------------------------------------------------------------

A conversation lasts exactly as long as the loaded page.

  - Closing and reopening the chat bubble KEEPS the conversation.
  - Refreshing the page STARTS A NEW conversation.
  - A second tab is a SEPARATE conversation.
  - Nothing is stored in the visitor's browser. There is no "New Chat" button
    and no previous transcript is ever restored.

This is deliberate, for privacy: a shared or public computer must never show
the previous visitor's chat.


--------------------------------------------------------------------------
KEEPING ANSWERS UP TO DATE
--------------------------------------------------------------------------

Ask Sid answers only from the website and course catalog. When content changes
it needs to re-read the site.

This happens automatically:
  - about 90 seconds after you publish or update a page, post, or course
  - once a day

To force it immediately:
  WordPress Admin -> Ask Sid KB -> "Update Chatbot Knowledge Now"

Give it about a minute, then reload a page and ask about the new content.


--------------------------------------------------------------------------
TROUBLESHOOTING
--------------------------------------------------------------------------

Bubble does not appear
  - Is the "Ask Sid" plugin Activated?
  - Is the [siddh_guide_chat] shortcode on the page?
  - Purge the page cache.
  - Open F12 -> Console and check for errors.

Bubble appears but every answer is an error
  - The API key is probably missing or wrong.
  - Check Ask Sid KB -> the status line should read "API key configured".

"I can help with Siddhanta course and website information..."
  - This is the intended reply when the question is outside the website
    content. It is not an error.
  - If it happens for content that IS on the site, run
    "Update Chatbot Knowledge Now".

Answers forget the previous message
  - Confirm you did not reload the page between messages (a reload always
    starts a new conversation - that is by design).
  - If it happens without a reload, tell us: it means the backend could not
    reach its conversation store, which we can see in our logs.


--------------------------------------------------------------------------
TECHNICAL REFERENCE (for the developer only)
--------------------------------------------------------------------------

Plugin name       Ask Sid  (folder: siddh-guide-chat)
Shortcode         [siddh_guide_chat]
Admin screen      Ask Sid KB
Browser calls     POST /wp-json/siddh/v1/chat
                  (the plugin adds the API key and forwards it to AWS)
wp-config keys    SIDDH_CHAT_API_KEY       (required)
                  SIDDH_CHAT_BACKEND_URL   (optional, overrides the default)

Files in the package
  siddh-guide-chat.zip
    siddh-guide-chat/siddh-guide-chat.php
    siddh-guide-chat/assets/siddh-guide-chat-widget.js
    siddh-guide-chat/assets/style.css
    siddh-guide-chat/assets/siddhanta-logo.png

Nothing else needs to be uploaded anywhere.
